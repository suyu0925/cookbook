# 猪梅花肉

## 苹果炖猪排（段小段）

食材
- 梅花肉550克，片成大拇指厚的厚片，用切断一下筋
- 腌肉料：盐5.5克，也就是1%，黑胡椒1克，油8克，洋葱适量

配料
- 洋葱1个，切瓦片块
- 大苹果1个，或小苹果2个，切成块，每块都要带点皮，方便后续挑出
- 姜片8-10片，
- 大蒜6-8瓣，掐头去尾后轻轻拍一下
- 动物黄油20克，安佳黄油2小盒

料汁
- 黑胡椒0.5克
- 肉桂粉0.5克
- 红糖11克
- 一品鲜酱油22克
- 蚝油9克
- 白兰地14克

预处理
- 梅花肉加盐、黑胡椒、油、洋葱，拌匀后静腌30分钟

烹饪
- 锅先烧冒烟，关火倒油
- 下肉排，开大火，煎一面金黄
- 翻个面，同时下姜片蒜粒
- 另一面也煎金黄后，改小火，下黄油，淋入料汁
- 猪排再翻个面，改中火，爆香料汁
- 下洋葱、苹果块（皮朝上，易挑），加开水，淹没猪排
- 盖盖中小火炖10-15分钟
- 留一点汤汁停火，先挑出苹果和洋葱铺在盘底，肉排拿出切条，铺在苹果和洋葱上
- 收浓汤汁，浇在肉排上，上菜

网友补充：
- 可以不需要用白兰地，腌肉的时候加一点白酒，炖的时候放一点好醋调酸度也可以
- 腌的时候不要放胡椒，煎完会糊，炖的时候放就可以
- 肉老的话，腌的时候可以用姜汁嫩化
- 如果肉比较肥，出油多的话，下黄油前可以先倒掉一点油

## 黑椒梅花肉（大仔食记）

食材
- 梅花肉400克

配料
- 红甜椒
- 洋葱

碗汁
- 多磨一点黑白胡椒
- 1勺生抽
- 半勺老抽
- 1勺蚝油
- 1勺蜂蜜（没有的话换成糖）
- 小半碗清水

预处理
- 梅花肉洗净擦干水分，片切成2公分左右的厚片，来点白胡椒、1勺生抽、花生油抓匀腌个底味

烹饪
- 润锅，留底油，中小火慢煎两面上色
- 小火，剪成小块
- 加入蒜粒，大火炒香
- 分两次倒入碗汁煮入味
- 大火收汁到差不多，勾一个薄芡
- 下入彩椒和洋葱炒到断生即可出锅
