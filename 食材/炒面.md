# 炒面

## 烹饪

### 炒火鸡面（村驴）

食材
- 1袋火鸡面
- 小油菜120克，洗净控干水份，把菜梗和菜叶分开，菜梗一分为二
- 火腿肠100克，斜刀切成片
- 西红杮165克，去皮去蒂，切成薄片
- 鸡蛋2个，打散

配料
- 洋葱50克，约1/6个，切丝
- 美人椒30克，约1根，斜刀切圈
- 大蒜15克，约3粒，切蒜末，和辣椒放一起

调料
- 蚝油10克，约半平勺
- 清水70克，约7勺
- 生抽10克，约1勺

预处理
- 火鸡面的面饼冷水下锅，水开后再煮1分钟捞起，不用过凉。如果是细面，水开后面条散了就可以捞出来。因为后面还要炒，所以不需要熟度太高。
- 火鸡面的酱包，加蚝油，清水搅匀

烹饪
- 热锅热油，比正常炒菜的油要更多一点
- 缓缓倒入蛋液，用筷子挑开已经凝固的蛋块，让上面的也流到油里凝固发起
- 下入火腿肠煎出焦边
- 倒入蒜末和辣椒，炒香
- 倒入西红杮，沿锅边淋生抽，改中火炒香，不要把西红杮的汁水给炒干了
- 西红杮炒的有点粘糊了，下油菜和洋葱，改大火炒匀
- 下面条，下调好的酱汁，翻炒均匀
- 让它咕嘟一会，炒到汤汁粘糊，出锅
