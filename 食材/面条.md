# 面条

## 烹饪

### 辣椒炒肉拌面（蚊子学做美食）

食材：
- 新鲜面条
- 瘦肉400克
- 洋葱半个切丝
- 螺丝椒1颗切丝
- 胡萝卜1根擦丝
- 西红杮1颗切大丁
- 姜末
- 大蒜6瓣切末

预处理：
- 瘦肉切片后需要先进行腌制，生抽、老抽、黄酒，抓进肉里。然后加一点随便土豆还是玉米还是红薯淀粉拌匀。如果是现腌现做，就没必要封油了。
- 水开后下面条，煮开后加一次冷水，再次煮开就只可以捞出来投凉。留半碗煮面原汤，后面要用。

烹饪：
- 起锅烧油
- 小火下入姜末和一半的蒜末，爆出香味
- 下猪肉，大火炒到变色
- 之后下入所有的配菜
- 开始调味：盐1小勺、味精1小勺、一点生抽
- 把沥完水的面条盖在顶部，再来盐1小勺、味精1小勺、两勺生抽、1勺老抽、1勺蚝油
- 保持大火，炒匀
- 闻到明显的香味后，沿锅边倒入煮面原汤，煨1分钟左右
- 锅边加入少许香醋，倒入剩下一半蒜末，翻拌均匀
