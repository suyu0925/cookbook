# 土豆

## 烹饪

### 酸辣土豆丝（村驴）

食材：
- 脆土豆，650克，约2个

配料：
- 2根薄皮青椒（65克），大的话就用1根，从中间片开，斜着切成丝，单独装在小碗中
- 根据口味，弄点小米辣（40克，6根），去掉蒂，从中间片开就行了，不用再切成丝，这样口感更好
- 再根据口味，剪一点干辣椒段（2根）
- 大蒜4粒（20克），直接切片，和辣椒放一起
- 香菜去掉叶只要梗（15克），切成小寸段

调料：
- 生抽20克，2勺
- 老抽3克，1勺尖
- 盐5克，1平茶勺多一点点，1平茶勺为3克
- 味精3克，1平茶勺
- 白糖5克，1平茶勺多一点点
- 陈醋20克，2勺

预处理：
- 土豆洗净，擦成中等粗细的丝
- 用清水多投洗几次，一直洗到水清
- 然后用加一勺白醋的水泡10分钟
- 炒之前提前一点沥干

烹饪
- 热锅凉油，加一勺猪油，或者加五花肉也行片
- 来个小密漏，捏一捏花椒粒，不用等油热，放在油里爆香。花椒爆香变成深紫色就拿走扔掉，不要焦了
- 关火，等油降温
- 关火状态，直接下辣椒和蒜片，炒香
- 加生抽和老抽，开大火，爆出酱香
- 马上下入土豆丝，狂炒1分钟，炒软土豆丝
- 保持大火，下入青椒丝炒匀
- 加盐、糖、味精，下入香菜杆，炒匀
- 加陈醋，炒匀出锅


### 宝宝孜然土豆泥（安秋金）

食材：
- 黄心土豆

调料：
- 黄油
- 芝士
- 牛奶
- 黑胡椒粉
- 孜然粉
- 蚝油
- 盐
- 生抽
- 老抽
- 水淀粉

烹饪：
- 起宽水，土豆洗净，带皮冷水下锅，大火烧开，盖盖转小火焖30分钟以上（煮到可以用小刀丝滑插入）
- 时间到，土豆捞起冲凉水，去皮，用饭勺压成泥，有筛子的话过一下细筛，会更细滑
- 重新起锅（最好不粘锅），最小火，加黄油10克，倒入土豆泥，加一片芝士，少量多次的加入牛奶（50-100ml），搅拌到表面光滑
- 铺保鲜膜，放上土豆泥晾凉，然后放入一个小碗，把土豆泥表面抹平，这一步是做造型
- 重新起锅，自喜量黑胡椒粉、孜然粉，盐、蚝油1勺、老抽、生抽、清水搅匀调盐口
- 少量多次给水淀粉勾芡
- 拿盘子倒扣在土豆泥的碗上，将土豆泥翻转过来，类似扣肉一样
- 浇上芡汁，上菜

### 酸辣土豆丝（隋坡版）

食材：
- 土豆丝500克，切1-1.5毫米宽。切完后要多洗两遍，再泡15分钟才能脆。

配料：
- 蒜片
- 辣椒丝
- 香菜杆
- 盐
- 味精
- 香油
- 米醋40克
- 陈醋5克

烹饪：
- 热锅凉油，小火，下蒜片和辣椒丝炒香
- 改大火，下土豆丝，炒至变软变成半透明状。之后全程大火
- 开始调味：加入盐、味精、米醋、陈醋、香菜杆，炒匀
- 最后来点香油，出锅

扩展：
- 试了一次，用的千禾白醋，太酸了。下次试试30克。
